Hospital Management System (Admin Portal)
========================================

How to run
----------

1. Make sure you have Python 3 installed.
2. Install the required libraries (all from the standard library, so nothing extra is needed).
3. From a terminal, navigate into this folder and run:

   python main.py

Login credentials
-----------------

- Username: admin
- Password: admin123

Modules
-------

- Patients: register and manage patient records.
- Appointments: schedule and update visits per doctor.
- Room assignments: track inpatient stays and room allocation.
- Treatments: record procedures and costs.
- Billing: manage invoices and payment status.

The application uses a local SQLite database file named `hospital_admin.db`.
